# Product roadmap

This is a staged development direction, not a release calendar. Advance when the
exit criteria are supported by evidence. The original project report's 90-day
sequence and commercial ranges are planning hypotheses, not commitments.

| Stage | Focus | Exit criteria |
| --- | --- | --- |
| Visitor reliability | Android/iOS parity, reviewed monument packs, narration and weak-network recovery | Device matrix passes; content sources and interpretation labels reviewed; offline and permission-denial journeys exercised |
| Connected reporting | Website intake, private evidence, staff/site isolation and receipt status | End-to-end submission, retry, authorised review and resolution verified; cross-site access denied |
| Bounded site pilot | One authorised site, five checkpoints, Hindi/English journeys and staff training | Site permission, safe routes, content ownership, consent and measurement definitions agreed |
| Operational integrations | Compatible camera gateway, narrow event categories and authorised ticket inputs | Observation-only evaluation completed; false-alert burden and counting error documented; human-review workflow accepted |
| Repeatable rollout | Configurable sites, support, retention and recovery processes | Pilot continuation decision, tested restoration and repeatable installation evidence |

## Pilot measurement

Agree denominators and observation windows before collecting results:

- Visitor start rate: experience starts / eligible scan sessions.
- Completion: completed journeys / journey starts (record this denominator explicitly).
- Engagement: checkpoint progression, network failures and collected satisfaction.
- Alert quality: confirmed true detections / reviewed detections, plus false alerts
  per camera-hour and missed events when ground truth exists.
- Response: acknowledgement time, ownership, resolution and unresolved work.
- Adoption: staff usage, training completion and the site's continuation decision.

Targets are negotiated pilot criteria. No current customer count, revenue,
detection score or conservation outcome is asserted by this roadmap.

## Deliberate boundaries

Official ticket issuing, facial identification, autonomous enforcement and broad
predictive surveillance are outside the first pilot. Ordinary visitor camera use
must not silently become continuous control-room streaming. Valuable rewards need
stronger presence validation than a shareable checkpoint link.
